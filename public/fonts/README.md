# Fonts

`Inter-latin-variable.woff2` is Inter (variable, Latin subset) from the `@fontsource-variable/inter` 5.3.0 package, under the SIL Open Font License 1.1 (`Inter-OFL.txt`). It replaces the Google Fonts request so the app makes no third-party calls.

`Kalpurush.ttf` is the Bangla typeface used by the app. It is unmodified and unrenamed.
Developer: Tanbin Islam Siyam, under the Avro Font Development Project (Omicron Lab, http://www.omicronlab.com).
Licence: SIL Open Font License 1.0 (http://scripts.sil.org/OFL), as stated in the font's own metadata.
Do not rename or modify the font file; copying it verbatim is allowed.
